# Cefa Coffee Landing Page

A beautiful, responsive landing page for Cefa Coffee brand featuring warm brown theme, coffee menu, about our beans section, testimonials, and order/contact form.

## Features

- **Hero Section**: Warm brown gradient background with compelling tagline
- **Menu Section**: Display coffee items with clear pricing
- **About Our Beans**: Highlight organic sourcing and infusion flavors (lavender, cinnamon, chocolate)
- **Testimonials**: Customer photos and quotes for social proof
- **Order/Contact**: Mobile-friendly form and clear CTA buttons
- **Responsive Design**: Fully responsive layout using CSS Flexbox/Grid
- **Warm Brown Theme**: Consistent color palette throughout the site
- **Interactive Elements**: Mobile menu toggle, smooth scrolling, form validation

## Design Tokens

### Colors
- **Primary**: `#4B2E2A` (dark warm brown)
- **Secondary**: `#8B5E3C` (medium warm brown)
- **Accent**: `#D4A373` (light warm brown)
- **Background**: `#F5F1EA` (off-white/cream)
- **Text**: `#2E2E2E` (dark gray)
- **Muted**: `#777777`

### Typography
- **Heading Font**: `'Playfair Display', serif`
- **Body Font**: `'Source Sans Pro', sans-serif`
- **Heading Sizes**: 
  - h1: 2.5rem
  - h2: 2rem
  - h3: 1.5rem
  - h4: 1.25rem
- **Body Size**: 1rem
- **Line Height**: 1.6

### Spacing
- **Unit**: 0.5rem
- **Section Padding**: 4rem
- **Container Max Width**: 1200px

### Breakpoints
- **Mobile**: 480px
- **Tablet**: 768px
- **Desktop**: 1024px

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/cefa-coffee-landing-page.git
   ```

2. Open `index.html` in your browser to view the landing page

3. For development, you can use any local server (like Live Server in VS Code)
